# Phase 4: finite hierarchies and retained evidence

This directory preserves September 2026 research artifacts. It contains two scientific lines: finite representation hierarchies, and the evidence used to evaluate changing neural predictors. The retained-evidence report is part of the second line.

Read [scientific status](SCIENTIFIC_STATUS.md) for the limits of each claim and [reproduction instructions](REPRODUCE.md) for the difference between checking saved evidence and running new computations. Results and replay reports are historical; repository preparation did not rerun experiments or neural training.

The public data include all 336 neural run summaries, 8,064 event rows, 128 paired contrasts, all 153 retained-evidence base groups and 96 post-hoc groups, finite-population calculations, and source-mass proof diagnostics. A complete interaction seed 750000 neural run and its exact data/access counts are included. Other large raw neural histories and data remain in the local archive, identified by size and SHA-256 in [RAW_ARTIFACTS.json](RAW_ARTIFACTS.json). A hash identifies bytes; it does not make an omitted file available.

The finite-state retained-evidence counts are included, while their two large expanded JSONL tables are archived. Original generators, seeds, configurations, and full numerical summaries are retained. The repository preserves adverse proposal and fixed-width comparisons, oracle-resource qualifications, and post-hoc labels.
