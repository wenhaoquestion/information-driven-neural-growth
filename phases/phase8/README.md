# Phase 8: polynomial curvature and source weights

Start with the [v2 English paper](manuscript/curvature_hierarchy.pdf) and its [LaTeX source](manuscript/curvature_hierarchy.tex), by Wenyu Huang, University of California San Diego, dated 7 October 2026.

This late-stage theoretical study concerns the cost of requiring finite representations at different capacities to form one hierarchy. It contains equal-mass four-state bounds, a stronger construction with degree-dependent positive weights, and an arbitrary-finite-source upper bound.
