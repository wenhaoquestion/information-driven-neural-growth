# Historical Phase 8 v1

These authored TeX sources preserve the development of the curvature hierarchy argument. The current Phase 8 entry point is [v2](../../README.md); the subsequent four-state sharpening is in [Phase 9](../../../phase9/README.md).

This is a historical snapshot, not the current scientific status. In particular, the coarse all-capacity degree bound and older bibliographic wording were superseded. The v0 equal-mass logarithmic gap was closed by v1. Later changes are explained in the current scientific-status file.

From this directory, `sh build.sh` builds the historical paper with an existing TeX installation. No historical execution or approval logs are distributed. Author attribution remains in the original source.
