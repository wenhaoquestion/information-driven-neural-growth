# Publication transformations

Scientific numerical algorithms, configuration values, seed lists, result values and theorem statements are preserved. The public README/status/reproduction/index documents are new editorial entry points. Historical technical review prose is condensed into neutral technical summaries; internal role/model/tool descriptions and private instructions are removed. Machine paths in metadata are made phase-relative. Operational preservation/publication instructions are removed from the public Phase 6 protocol; its scientific design is unchanged.

Original freeze/result hashes refer to the historical bytes, including omitted full raw files and original prose. They must not be treated as hashes of a sanitized public counterpart. `PUBLICATION_MANIFEST.json` identifies the actual public bytes. `EXCLUDED_ARTIFACTS.csv` identifies excluded local originals, including duplicate evidence, caches, downloaded third-party full texts and private workflow records. A hash establishes identity, not scientific validity or public availability. No new license is assigned.

The historical compiled English paper remains unmodified; statements about full raw archives in it describe the original local research package. This public release intentionally contains compact evidence plus reproducible source/configuration, not the entire raw archive. Public readers need to regenerate omitted files before running full raw-dependent audits. Historical technical checks do not imply external peer review or personal review by the named author.

This publication pass executes no scientific training, simulation, random-number generation, bootstrap or scientific parameter search. Deterministic publication verification checks only the included record and source/build integrity.
