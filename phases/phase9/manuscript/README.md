# Phase 9 manuscript

The main paper is [phase9_weighted_quartet.pdf](phase9_weighted_quartet.pdf); its matching TeX source and all required input files are in this directory. Author: Wenyu Huang, University of California San Diego. Date: 7 October 2026.

Run `sh build.sh` with an existing TeX installation to compile with shell escape disabled. The script creates local build output and copies the compiled main PDF here. Compilation does not run the scientific Python scripts.

See [reproduction instructions](../REPRODUCE.md) and [scientific status](../SCIENTIFIC_STATUS.md). These are working-paper sources with explicit limitations; no external peer review or publication priority is certified.
