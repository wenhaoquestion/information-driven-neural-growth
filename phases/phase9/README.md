# Phase 9: sharp weighted four-state hierarchies

Start with the [English working paper](manuscript/phase9_weighted_quartet.pdf) and [LaTeX source](manuscript/phase9_weighted_quartet.tex), by Wenyu Huang, University of California San Diego, dated 7 October 2026.

This late theoretical phase closes the arbitrary-positive-weight four-state, two-/three-capacity degree envelope at Θ(r²/log² r), in deterministic and stochastic models. The self-contained paper includes the matching Phase 8 lower construction, a comparison-method obstruction, an explicitly restricted indicator-network bridge, and a classical polynomial-moment appendix.
