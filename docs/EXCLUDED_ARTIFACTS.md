# Exclusions and recovery

The public archive covers every research phase and the additive-risk follow-up, while excluding environments, caches, duplicate replay directories, old packaging ZIPs, machine logs, private research conversations and orchestration instructions. Third-party full papers are not redistributed; citations and source links remain. No Git LFS or external paid storage is required for this release.

Large generated raw arrays and per-trial logs remain in the local research archive. Public omission does not turn a completed historical run into a new release rerun, and a retained PASS receipt is not proof that an omitted raw audit can be run from this checkout. The scope and recovery path vary by stage:

| Stage | Included evidence and recovery boundary |
|---|---|
| 1 | Small core numerical tables, source, figures and historical checks are included. Development environments, rendered page images and duplicate packages are excluded. |
| 2–3 | Compact summaries and the full essential audit tables are included; eight gzip files preserve the large JSON payloads losslessly unless a recorded privacy transformation is stated. Saved-evidence checks read them directly. The stage restore helpers verify the uncompressed digest and refuse conflicting existing files. Large redundant raw logs and replays are excluded; follow stage manifests and protocols for regeneration. |
| 4 | All 336 run summaries, 8,064 events, summary contrasts, retention counts and a representative raw neural run are included. `phases/phase4/RAW_ARTIFACTS.json` identifies included and local-only raw files with original size and SHA-256. Full historical audits require the listed originals or an explicit regeneration using the preserved code, seeds and protocols. |
| 5 | Estimator-stage tables, 768 endpoint records covering 5,376 historical events, 1,440 branch records, main/adaptive event tables and summary analyses are included. `phases/phase5/EXCLUDED_ARTIFACTS.csv` identifies omitted arrays and duplicate execution material. The stage guide supplies optional full regeneration commands. |
| 6 | The complete 7,040-row trajectory table, recorded statistical decision, derived results and configs are included. `phases/phase6/EXCLUDED_ARTIFACTS.csv` identifies omitted state arrays, raw data and duplicates. AUCs can be reconstructed now; full saved-state and bootstrap audits have additional requirements. |
| 7 | This theoretical phase includes the proofs, deterministic tables, source and literature audit. It has no neural training set or trained model to recover. Duplicate renderings, machine metadata and private workflow records are excluded. |
| 8–10 | Main and supporting theory, calculations, numerical summaries, figures and bibliographies are included. Machine logs, duplicate replay/build trees and third-party article PDFs are excluded. Scientific failures and limitations are preserved in the stage technical notes. |
| Additive risk | Mathematical code, complete defined special loss, fixed confirmation counts, confidence and power certificates, and sanitized provenance are included. Wrapper/path changes are identified; the core certificate-bound algorithms retain their scientific identity. Private release bundles and operational records are excluded. |

The stage-specific `REPRODUCE.md`, `PUBLICATION_NOTES.md` or `PUBLICATION_PROVENANCE` records explain transformations and historical identities where relevant. The root `PUBLICATION_MANIFEST.json` hashes the current public files. Original hashes in a historical receipt may deliberately differ from a cleaned manuscript or portable wrapper; neither hash should be substituted for the other.

There is no automatic download command for local-only raw artifacts. To use an original retained locally, restore it to the stage-relative path specified by its ledger and verify its original SHA-256. Alternatively, use the stage’s explicit regeneration procedure in a disposable working copy. Generated arrays may differ at the byte level across library versions even when numerical tolerances agree. Until the required files exist, do not describe the corresponding full raw audit as reproducible from this checkout alone.
